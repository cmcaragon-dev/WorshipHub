CHORDIO V62 — MODERN UX + PRESENTATION CONTROL UPGRADE

Base: CHORDIO FINAL(4) - Lyrics Display Settings Fixed

1. Removed dashboard/sidebar Welcome panel.

4. Added visible Favorites (star) on song cards and Favorites dashboard panel.

9. Live Mode hides configuration controls and reduces the Multi-Screen interface to presentation/navigation essentials to reduce accidental changes.
10. Lyrics presets added: Standard, Large, Projector, Reset Defaults. Projector/default font size is 100 px.
11. Added modern toast notifications.
12. Added visible Auto-save status indicator in Multi-Screen control.
13. Added modern responsive UX styling, cards, dialogs, library panels and interaction states.
14. Existing Firebase/service/song/presentation architecture retained.

Live Mode meaning:
- PREPARE: configuration controls are available for setup.
- LIVE: configuration controls are hidden/locked from the main operator view; navigation and output control remain available.
- LIVE does not turn off the HDMI outputs; it is an operator-safety mode.
