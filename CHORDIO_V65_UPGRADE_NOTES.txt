CHORDIO V65 UI UPGRADE

Implemented requested dashboard/sidebar and Multi-Screen refinements:
1. Quick Actions now use modern Font Awesome icons and a cleaner card layout.
2. Removed the "Prepare Your Service" heading and the explanatory "Start a service..." text from Quick Actions.
3. Service Planner entries are collapsed by default; click a service header to expand/collapse the song list. Song count stays left and the date is aligned on the right.
4. Sidebar now shows "Hello, Welcome" above Quick Actions, with the authenticated user name displayed in gold.
5. Multi-Screen header copy no longer includes the excess HDMI-output wording.
6. Removed the Screen 1–4 selector controls above the Screen Output Preview. Preview remains available for the configured screens.
7. Multi-Screen Live button now always says "LIVE": gray when not active and blinking red when active.
