# CHORDIO V65 — Dashboard Layout and Sidebar Settings

Updates in this build:
1. Service Planner dates are displayed on the right side of each planner header and do not overlap the song count.
2. Every Service Planner remains independently collapsible; clicking its header expands/collapses the song list and controls.
3. Main dashboard now shows a personalized “HELLO, WELCOME” greeting using the signed-in user name above Quick Actions.
4. Multi-Screen Control no longer shows the explanatory HDMI subtitle beneath the title.
5. The old SCREEN 1–4 / HDMI OUTPUT settings strip above Screen Output Preview is hidden from the main preview area.
6. LIVE indicator is gray when inactive and blinks red while Live Mode is active.
7. Quick Action icons use Font Awesome and have refined cards, borders, hover states, spacing and icon tiles.


V65.1 update: applied on top of the exact CHORDIO V65 Dashboard Layout and Sidebar Settings package (not V61). Added persistent Service Planner collapse state, dynamic welcome-name sync, and a visible gray/blinking-red Live status icon.
