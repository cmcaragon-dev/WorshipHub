WorshipHub update – 2026-08-27

Main changes
1. Added an administrator-only Global Dashboard on index.html:
   - Total Service Planners, Playlists, Users, Songs, Artists and songs in services.
   - Admin can view creator/user details.
   - Admin can edit (rename; playlist also edits YouTube link) and delete Service Planners and Playlists.
2. Administrator email is cmcaragon@gmail.com.
3. Song-page Edit Song button is visible only to the administrator.
   - Editor now shows CHORDS above LYRICS.
   - Both chord spacing and lyrics can be edited.
   - Saved layouts are stored in Firestore as chordLayouts + lyricLayouts.
4. Add Song editor now stores chordLayout text and converts chord tokens to structured chord positions.
   This keeps the exact horizontal spacing and supports transposition of every chord.
5. Custom songs now render one monospace chord span above the matching lyric line and transpose every chord token while preserving spaces.
6. Presentation has a responsive black full-viewport design, two columns on larger screens, one column on small screens, internal scrolling, compact header, and next-song preview in the lower-right.
7. Standalone and Service Print use three equal columns. Service Print forces one complete song per printed page.
8. Print Preview remains editable for section placement (C1/C2/C3 and Up/Down), and the preview paper is actually printable instead of disappearing under @media print.
9. Added responsive index/service-planner styling.

IMPORTANT FIREBASE STEP
The included firestore.rules file must be published to the Firebase project.
In Firebase Console -> Firestore Database -> Rules, replace/publish the rules from:
    firestore.rules

The rules authorize the administrator by Firebase Auth email:
    cmcaragon@gmail.com

Browser fullscreen note:
The presentation automatically opens as a full-viewport overlay. Browsers may block true OS/browser fullscreen when it is triggered without a direct user gesture. The Maximize button remains available for true fullscreen.

The package contains the original project plus these revisions.

V43 CUSTOM SONG / PRESENTATION FIXES - 27 AUG 2026
- Custom-song page now renders saved chord positions by character index, so chord placement remains at the exact location entered by the admin even when chord text is displayed smaller.
- Custom-song chord font is reduced to 70% of the lyric grid size without changing its horizontal character position.
- Custom songs now use the same standard presentation runtime and presentation UI as the built-in HTML songs, including responsive full-screen display, two-column flow, scroll, passing chords, service navigation, next-song preview, settings, maximize and close controls.
- Custom-song presentation automatically opens when the custom song is opened from a Service Planner.
- Fixed presentation navigation URLs when moving between custom songs and built-in HTML songs.
- Custom-song editor now clearly places the chord input above the lyric input for each line.

V43.1 / V44 CHORD ALIGNMENT FIX
- Fixed custom Add Song chord positioning by measuring the lyric font's actual monospace character width.
- Chord font remains smaller (70%) without changing the horizontal position entered by the admin.
- Presentation now uses a guaranteed two-row chord/lyric grid: chord row directly above lyric row, with no vertical gap or overlap.
- Consecutive song lines have zero added margin/padding between them.
- Presentation chord positions are rebuilt from the exact saved chord-layout character positions.
