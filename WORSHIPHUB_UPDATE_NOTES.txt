WorshipHub V47 Update

1. Presentation chords
- Chords now use the same font size and font metrics as the lyrics.
- Each chord row occupies a full line directly above its lyric row, eliminating vertical overlap.
- Horizontal chord positions remain based on the exact character offsets entered in the source HTML/Add Song layout.
- Presentation remains vertically scrollable for long songs.

2. Global Admin Dashboard
- Removed the Service Planners, Playlists, and Users detail panels from the visible dashboard body.
- The clickable statistic cards remain.
- Clicking Service Planners, Playlists, or Users opens the existing detail modal with its Close button.

3. Validation
- JavaScript syntax checked for presentation-runtime.js and admin-settings.js.


WorshipHub v48 fixes (2026-08-27)
- Presentation now renders every song line as a strict two-row block: chord row first, lyric row second.
- Presentation chord font size is exactly the same as the lyric font size.
- Presentation chord horizontal positions continue to use the saved chord character positions from the HTML/Add Song layout; no compression based on chord font size.
- Removed vertical gap between chord and lyric rows and between consecutive song lines.
- Global Admin Dashboard no longer renders Service Planner, Playlist, or User record lists underneath the dashboard. Those lists are generated only when the corresponding statistic card is clicked and displayed in the detail modal.


V48.2 FINAL FIXES
- Presentation chord layout now preserves all whitespace from the original <span class="chord"> source.
- Chord horizontal positions are calculated from the original character index and the lyric monospace character width; no trimming, centering, flex distribution, or reflow is applied.
- Presentation chords use the same font size and font metrics as the lyrics and occupy a dedicated row directly above the lyrics.
- Global Admin Dashboard is now an on-demand admin-only view opened from a new Dashboard item in the sidebar.
- The normal All Songs page no longer shows dashboard cards or the Global Dashboard in the center.
- Service Planner, Playlist, and User lists remain in modal/detail windows only and are not rendered below the dashboard.
